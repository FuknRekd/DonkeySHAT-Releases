# Known v0.2.3 limitations

- Manual Mode only; task and result transfer require user action.
- Full automation is disabled.
- Final response text selection has limitations; selecting/copying output may be awkward.
- Reporting UI has contrast issues that can reduce readability.
- No embedded interactive terminal. Do not expect an interactive shell session in the GUI.
- No integrated onboarding wizard. Prerequisites and authentication are manual.
- Unsigned executable; broad Windows/DPI, migration and USB deployment certification
  are not claimed for this download.

Review task results independently. Successful commands or process exit alone do
not establish that the requested objective was achieved. This feature-frozen
release does not include unfinished development work.
