# DonkeySHAT v0.2.3

Feature-frozen Windows x64, framework-dependent Manual Mode release.
The tested application binaries are unchanged in this documentation-only repack; there is no rebuild
or new feature in this distribution preparation. Corrected theme resources are
included in the tested archive.

Requires Windows x64, .NET 10 Windows Desktop Runtime x64, WebView2 Runtime,
configured Codex CLI and the user's own authentication.

Known limitations: Manual Mode only; Full automation disabled; final response
text selection limitations; reporting UI contrast issues; no embedded interactive
terminal. Installation and authentication are manual; no wizard is included.
